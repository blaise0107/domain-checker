# Domain Checker

Десктопное приложение для проверки домена на роутере Keenetic с NFQWS2 Strategy Selector.
Вводите домен — приложение собирает доказательства и говорит **куда именно прописывать** домен
(список nfqws2, DNS-правило, VPN-туннель или «ничего не трогать»).

## Принцип

Приложение **только читает** состояние роутера; оно никогда не меняет конфиг. Все команды в карточке
результата нужно выполнять вручную (кнопка «Копировать команды»).

Логика взята из проверенной методики:

- `../02_Keenetic_Router/diagnostics.md`
- `../02_Keenetic_Router/domain-lists.md`
- `../02_Keenetic_Router/dns-server-rules.md`
- `../03_Bypass_RKN/warp-and-tunnels.md`
- локальный skill `diagnosing-blocked-domains-keenetic` (не входит в репозиторий)

## Уровни блокировки

| Уровень | Признак | Что делать |
|---|---|---|
| **DNS** | резолвер отдаёт мусор/пусто | доменное правило DNS Server + «включая поддомены» |
| **SNI** | IP верный, TLS висит/рвётся | `list-general.list` + рестарт nfqws2 |
| **IP/порт** | conntrack `SYN_SENT`, `unreplied`, 0 байт | VPN/WARP-туннель (на клиенте) |
| **Регион** | сайт отвечает «unsupported region» | на роутере не лечится |
| **Нет блока** | `blocked=false`, 403/404 — не блок | роутер не трогать |

## Установка и запуск

Из исходников:

```powershell
cd domain-checker
python -m pip install -r requirements.txt
python -m src.main
```

Сборка одного `.exe`:

```powershell
python -m PyInstaller build.spec --noconfirm
# результат: dist\DomainChecker.exe
```

Готовый `DomainChecker.exe` можно скопировать в любую папку — база знаний (`data/`) встроена в файл.
Настройки и история сохраняются **рядом с exe** в `config.local.json` и `history.json`.

## Подключение к роутеру

По умолчанию (менятся в «Настройки»):

- панель NFQWS2 Strategy: `http://192.168.1.1:8090` (авторизация выключена) — отсюда берутся BlockCheck, DNS и conntrack;
- панель `nfqws-keenetic-web` (обход РКН/YouTube): `http://192.168.1.1:90/` — добавлена кнопкой «Панель :90 (обход РКН)»; это отдельный nfqws v1, дублирующих замеров не делает;
- SSH Entware: по умолчанию `root` /заводской пароль `keenetic`, порт `222` (фолбэк `22`); если пароль изменён — задайте его в окне «Настройки». Сохранение пароля в `config.local.json` по умолчанию **выключено** (во избежание plaintext); SSH-ключ хоста сохраняется в `known_hosts.txt` и проверяется при следующих подключениях;

Если SSH недоступен — приложение продолжает работать, но не сможет проверить, есть ли домен
уже в списках и в `dnsserver.json`. Если недоступна панель — вердикт строится только по базе знаний
и помечается как «низкая уверенность».

## Что показывает карточка

1. **Вердикт** — уровень блокировки, заголовок и пояснение.
2. **Доказательства** — BlockCheck, DNS A, conntrack, вхождение в списки nfqws2, правила DNS Server.
3. **Куда прописывать** — точный путь, строка для добавления, готовый фрагмент команд с кнопкой копирования,
   ссылка на нужную панель.
4. **Предупреждения** — WARP обесценивает curl с ПК, `403` — не блок, `cursor.sh ≠ cursor.com`,
   nfqws2 читает списки только на старте и т.д.
5. **Отчёт** — экспорт в Markdown, кнопка «Скопировать для ИИ» (готовый промпт со всеми доказательствами) и история проверок (последние 200 записей, без повторов доменов).

## Удобство использования

- **Положение и размер окна** сохраняются автоматически (Windows Registry через `QSettings`) и восстанавливаются при следующем запуске.
- **Иконка** приложения — на exe и на окне; ярлык Windows показывает её после пересборки (при необходимости обновите ярлык).
- **Режимы подсказок** — переключатель «Подсказки» вверху окна (и в «Настройках»):
  - **Новичок** — простыми словами: «Сайт заблокирован Роскомнадзором», «Сервис не пускает пользователей из России», пошаговые действия 1-2-3-4, подсказки при наведении на каждый элемент;
  - **Средний** — прежний уровень детализации с точными путями и командами;
  - **Профи** — сырые данные, все доказательства и кнопка «Скопировать для ИИ» с готовым промптом.
- **Терминал роутера** — кнопка «Терминал роутера» открывает интерактивную SSH-консоль Keenetic с уже подставленными логином и паролем из настроек; команды из подсказок можно вставлять прямо туда. При смене ключа хоста показывается предупреждение о возможной MITM-атаке.
- **Доказательства и подводные камни** — в главном окне блоки компактные, чтобы не сжимать интерфейс на маленьком экране. Кнопки «Открыть полностью ↗» открывают отдельные просторные окна:
  - «Доказательства» — таблица с тремя колонками (проверка / результат / статус), при клике по строке справа показываются подробности, есть копирование всего текста;
  - «Подводные камни» — полные предупреждения и ловушки с копированием;
  - «Эталонные записи из базы знаний» — все сопоставленные записи из `data/domains.json` с пояснениями.
  Все три окна запоминают свои размеры и положение. Длинные строки в таблице прокручиваются по горизонтали; цвета: зелёный — всё нормально, оранжевый — внимание, красный — проблема.
